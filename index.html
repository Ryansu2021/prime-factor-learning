重點一・因數與倍數

什麼是「因數」與「倍數」？

整除與乘法算式

當正整數 $a \div b$ 沒有餘數（整除），就可以改寫成乘法算式：

$a = b \times c$
  • ✔️ 因數：$b$ 與 $c$ 都是 $a$ 的因數。
  • ✔️ 倍數：$a$ 是 $b$ 的倍數，也是 $c$ 的倍數。

實例：$12$ 的因數

把 $12$ 顆蘋果排成長方形，有幾種排法？

$12 = 1 \times 12$ $12 = 2 \times 6$ $12 = 3 \times 4$

📌 $12$ 的正因數：$1, 2, 3, 4, 6, 12$（共 $6$ 個），而且是兩兩成對出現的。

📌 任何正整數 $N$，最小的正因數是 $1$，最大的是 $N$ 本身。

不用除法也能判斷

$2, 3, 4, 5, 9, 11$ 的倍數判別法

$2$ 的倍數看個位

個位數字是 $0, 2, 4, 6, 8$。

例：$528$ 個位是 $8$ → 是 $2$ 的倍數。
$5$ 的倍數看個位

個位數字是 $0$ 或 $5$。

例：$735$ 個位是 $5$ → 是 $5$ 的倍數。
$4$ 的倍數看末兩位

末兩位是 $4$ 的倍數（或 $00$）。

例：$1528$ 末兩位 $28 = 4 \times 7$ → 是 $4$ 的倍數。
$3$ 的倍數數字和

各位數字的和是 $3$ 的倍數。

例：$528 \to 5+2+8=15$ → 是 $3$ 的倍數。
$9$ 的倍數數字和

各位數字的和是 $9$ 的倍數。

例：$468 \to 4+6+8=18$ → 是 $9$ 的倍數。
$11$ 的倍數奇偶位差

從個位起，奇數位數字和與偶數位數字和的差是 $0$ 或 $11$ 的倍數。

例：$528 \to (8+5)-2=11$ → 是 $11$ 的倍數。

重點二・質數與合數

質數 vs 合數

🌟 質數

恰好 2 個正因數

大於 $1$ 的正整數，正因數只有 $1$ 和它自己。

例：$7$、$13$、$53$

🧩 合數

3 個以上正因數

大於 $1$ 的正整數，除了 $1$ 和自己，還有其他正因數。

例：$6 = 2 \times 3$、$9 = 3 \times 3$、$51 = 3 \times 17$
1

$1$ 既不是質數，也不是合數

$1$ 的正因數只有 $1$ 個。

2

$2$ 是最小的質數，也是唯一的偶質數

但「奇數」不一定是質數，例如 $9$、$51$。

標準分解式

質因數與標準分解式

🔹 質因數：既是因數、又是質數的數。例如 $12$ 的因數中，$2$ 和 $3$ 是質因數。

🔹 質因數分解：把一個合數寫成質因數的乘積，例如 $72 = 2 \times 2 \times 2 \times 3 \times 3$。

🔹 標準分解式：相同的質因數寫成次方，底數由小到大排列：$72 = 2^3 \times 3^2$。

📜 為什麼可以叫「標準」？不管你先用哪個質數去除，最後得到的質因數（不計順序）都一樣——每個大於 $1$ 的正整數，質因數分解的方式只有一種。這個事實叫做算術基本定理，高斯在 1801 年的《算術研究》中首次完整地敘述並證明它。
